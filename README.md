## Wie erstelle ich ein neues Repository?

Ein neues Repository auf GitHub kann in wenigen Schritten erstellt werden:

### Schritt 1: Bei GitHub anmelden
Melde dich unter [github.com](https://github.com) mit deinem Benutzerkonto an.

### Schritt 2: Neues Repository erstellen
1. Klicke oben rechts auf das **+**-Symbol und wähle **„New repository"** aus.
2. Alternativ: Gehe auf dein Profil und klicke auf den Reiter **„Repositories"**, dann auf die grüne Schaltfläche **„New"**.

### Schritt 3: Repository konfigurieren
Fülle die folgenden Felder aus:
- **Repository name**: Vergib einen eindeutigen Namen für dein Repository.
- **Description** *(optional)*: Füge eine kurze Beschreibung hinzu.
- **Sichtbarkeit**: Wähle zwischen **Public** (öffentlich) und **Private** (privat).
- **README initialisieren**: Aktiviere die Option „Add a README file", um das Repository mit einer README-Datei zu starten.
- **.gitignore**: Wähle optional eine passende `.gitignore`-Vorlage für deine Programmiersprache.
- **Lizenz**: Wähle optional eine Lizenz für dein Projekt aus.

### Schritt 4: Repository erstellen
Klicke auf die grüne Schaltfläche **„Create repository"**. Dein neues Repository wird erstellt und du wirst direkt dorthin weitergeleitet.

### Schritt 5: Repository lokal klonen (optional)
Um das Repository auf deinem lokalen Rechner zu verwenden, führe folgenden Befehl im Terminal aus:

```bash
git clone https://github.com/<dein-benutzername>/<repository-name>.git
```

Ersetze `<dein-benutzername>` und `<repository-name>` durch die entsprechenden Werte.

---

Weitere Informationen findest du in der [offiziellen GitHub-Dokumentation](https://docs.github.com/de/repositories/creating-and-managing-repositories/creating-a-new-repository).
